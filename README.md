# Игра в кальмара — 2D

Браузерная фан-игра «Красный свет — зелёный свет». Без сборки и зависимостей.

## Запуск

```sh
cd /workspace/Squid_game
python3 -m http.server 3000 --bind 0.0.0.0
```

Откройте порт 3000 через доступное в вашей среде веб-превью. Удерживайте пробел, ↑, W или экранную кнопку «Идти». Отпускайте управление на красный свет. Доберитесь до финиша за 60 секунд. При смене сигнала есть 0,3 секунды на реакцию. При переключении вкладки игра приостанавливается. Звук включается отдельной кнопкой; рекорд сохраняется в браузере.

Внешние сервисы и ключи не нужны. Используется системный шрифт; все ресурсы находятся в репозитории.
